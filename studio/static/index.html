YOUR HARDWARE

Built around a smaller footprint.

For an RTX 3060 and 32 GB RAM, start with Qwen3 4B or 8B Q4 and an SD 1.5 image pipeline. SDXL needs more GPU memory; short, low-resolution videos are a sensible starting point. Available VRAM depends on your 3060 variant.

Refer to README.md for supported models, installation, and GPU dependencies. Noise cleanup, video edits, image animation, and built-in game templates work without AI model weights.

Offline means offline.

No cloud inference providers are included. The browser talks to this app, language inference talks to local Ollama, and image/video inference reads local model files. Sound cleanup uses local FFmpeg filters.

Install packages and acquire model files beforehand, or transfer them from another machine. Once set up, disconnect from the internet.
